# Package fixtures

The committed files under `inst/fixtures/` are package-owned reduced or
derived synthetic structures used to exercise parser, schema, validation,
cache, and deterministic documentation workflows. They are not copies of
official reports, workbooks, web pages, logos, a Coat of Arms, or third-party
source values.

Package code and these package-owned synthetic fixtures are licensed under
MIT, copyright Chartwell Macro. That package licence does not grant rights to official
publications, source data, provider material, names, marks, or logos.

The crop, agricultural-commodities, farm-productivity, and historical-forecast
fixtures contain small deterministic tables that retain the shapes and edge
cases needed by the tests. The Weekly HTML, text and PDF fixtures are likewise
synthetic profiles, including explicit blank, bounded and provider-error cells
for historical parser branches. The `Synthetic fixture` marker in generated
pages and reports is intentional.

Names and URLs in the package registries and catalogues are metadata used to
test identity, routing and provenance. They do not imply that the fixture
bytes contain the named source's prose, branding or observations. Live
endpoints remain the source path for live reads; these fixtures are offline
test and documentation inputs only. Charts built from them are labelled as
synthetic parser demonstrations rather than official observations.
