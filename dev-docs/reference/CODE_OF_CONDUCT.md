# Code of conduct

<!-- Development reference; excluded from the package tarball. -->

## Our commitment

We are committed to a respectful, inclusive and evidence-focused project.
Participants must be able to ask questions, report defects and challenge
technical decisions without harassment, discrimination or retaliation.

## Expected behaviour

- Be welcoming and patient.
- Critique code and evidence, not people.
- State uncertainty and correct mistakes openly.
- Respect privacy, source-data rights and responsible disclosure.
- Avoid sexualised language, personal attacks, intimidation and sustained
  disruption.

## Enforcement

Maintainers may edit or remove contributions and restrict participation when
behaviour undermines a safe, constructive project. Reports should be made
privately through the repository owner or an established private channel.

Reports will be handled as confidentially as practical. Retaliation against a
reporter or review participant is prohibited.
