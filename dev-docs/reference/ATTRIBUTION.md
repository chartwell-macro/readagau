# Attribution and terms

<!-- Development reference; excluded from the package tarball. -->

`agau_attribution()` and `crop_report_attribution()` provide attribution
guidance, but they are not a licence grant. Terms are source-specific. Some
ABARES publications state CC BY 4.0, subject to the terms and exclusions in
the particular source. This package therefore makes no package-wide CC BY or
source-data redistribution claim. Excluded material includes the Commonwealth
Coat of Arms, trade marks, and third-party material.

Weekly commodity-price results retain snapshot-date, upstream-provider,
published-unit, and accessible-chart provenance. That provenance does not
assert redistribution permission; each provider's terms must be checked for
the intended use.

Committed fixtures are package-owned reduced/derived synthetic structures.
They contain no official source bytes, logos, or third-party values. Source
URLs and provider names in package catalogues are metadata and attribution
references, not a claim that source values may be redistributed.

Weekly commodity-price providers identified by ABARES are recorded as
`review-required`. Fertiliser metadata records the unresolved Fabric/Power BI
endpoint and ICS/Argus rights blockers. Unknown rights never default to
permitted. Package code and package-owned synthetic fixtures are licensed
under MIT, copyright Chartwell Macro; that package licence does not cover source data
or third-party material.
