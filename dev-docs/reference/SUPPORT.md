# Support

<!-- Development reference; excluded from the package tarball. -->

## Where to ask

Use the [chartwellmacro@gmail.com](mailto:chartwellmacro@gmail.com)
for reproducible bugs, documentation gaps and non-sensitive usage questions.
Do not disclose credentials, restricted source files or vulnerability details
in a public issue. Follow [`SECURITY.md`](SECURITY.md) for security reports.
No response-time or support-service guarantee is made.

## What to include

Provide:

```r
sessionInfo()
packageVersion("readagau")
```

Also include the product, exact `release_id`, selected assets/datasets/view,
parser version, condition class and a minimal example. Never attach an
official workbook, downloaded report, restricted cache or credentials. Source
URLs and SHA-256 hashes identify assets without attaching their bytes.

## Support boundaries

The project can help with package behaviour and audited source layouts. It
cannot provide legal advice, guarantee availability of government or
third-party systems, or represent a discovered-unverified release as
supported. Weekly values retain source-provider and rights/provenance fields;
review the upstream terms before redistributing or publishing them.
