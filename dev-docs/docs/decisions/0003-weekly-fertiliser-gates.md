# Decision 0003: weekly-price and fertiliser admission gates

Status: not admitted; metadata-only, 2026-07-27

## Weekly commodity prices

The official ABARES HTML table is replayable and structurally accessible.
However, the linked attribution material identifies third-party providers
including IGC, USDA, Cotlook, ICE, AWEX, Jumbuk, MLA and GDT without granting
redistribution permission for their values. Series rights therefore default to
`review-required`. Metadata may be catalogued, but public values are not
admitted.

`unsupported_reason`: `series-level redistribution rights are not documented
as permitted for the intended public-value path`.

## Fertiliser

The official page embeds Microsoft Fabric/Power BI. No stable public replayable
structured endpoint or data dictionary has been established. Key figures cite
ICS and Argus, and reuse rights for underlying third-party values have not been
established.

`unsupported_reason`: `no documented stable official replayable structured
endpoint/data dictionary and no reviewed permission for underlying
third-party values`.

Neither source can satisfy the gate through chart pixels, an unversioned
private endpoint or inferred permission. These decisions do not block the
file-backed v0.1 products.
