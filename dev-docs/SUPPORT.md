# Support

<!-- Development reference; excluded from the package tarball. -->

## Where to ask

After the public repository is configured:

- use issues for reproducible bugs and documentation gaps;
- use discussions for usage questions and design proposals; and
- use the private security channel for vulnerabilities.

The project does not yet claim a public support URL. Do not send requests to
the placeholder address in `DESCRIPTION`.

## What to include

Provide:

```r
sessionInfo()
packageVersion("readagau")
```

Also include the product, exact `release_id`, selected assets/datasets/view,
parser version, condition class and a minimal example. Never attach an
official workbook or restricted cache. Source URLs and SHA-256 hashes identify
assets without redistributing them.

## Support boundaries

The project can help with package behaviour and audited source layouts. It
cannot provide legal advice, guarantee availability of government or
third-party systems, or represent a discovered-unverified release as
supported.
